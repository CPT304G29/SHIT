## Add Three.js Particle Galaxy Easter Egg

### What
A hidden easter egg that displays a particle animation forming "SHIT" and the full project name using Three.js.

### How to Trigger
1. Go to the Inventory page
2. Type `shit` in the search box
3. Press Enter

### Features
- 12,000 particles converge from a cloud to form text
- Mouse interaction: particles repel when cursor is nearby
- Mouse trail: particles follow cursor movement
- Ripple effect: subtle wave animation on the text surface
- Color pulse: gentle red color shift over time
- Click anywhere to dismiss

### Tech Stack
- Three.js for 3D particle rendering
- Custom GLSL shaders for particle glow and color effects
- Additive blending for luminous appearance
